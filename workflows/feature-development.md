# Feature Development Workflow

## Purpose
Use this workflow when a new feature or capability is being introduced.

## Stages
1. Planning
   - Gather requirements and constraints.
   - Use the planning template.
2. Implementation
   - Build the feature using the implementation template.
   - Keep worker agents scoped to the relevant context folders.
3. Review
   - Validate the result against quality and standards.
   - Use the review template.
4. Release
   - Deliver the outcome and capture operational notes.
   - Use the release template.
